# 単語帳の札を TSV で作る

単語帳アプリは、タブ区切りのテキスト（TSV）を貼り付けて札を一括で取り込む。
この文書の形式に合わせて出力すれば、利用者はそのまま「TSV から取り込む」画面に貼り付けられる。

## 1. 形式

- 1 行に 1 枚。列はタブで区切る。列の順は固定で、次の 5 列。

| 列 | 内容 | 必須 | 上限 |
| --- | --- | --- | --- |
| 表 | 問い。用語、または問題文 | 必須 | 2000 文字 |
| 裏 | 答え。用語の説明、または正解 | 必須 | 4000 文字 |
| 補足 | 答えの根拠や覚え方。記述のときの「ヒント」にも使う | 任意 | 4000 文字 |
| タグ | 分野の名前。読点（、）かカンマで区切る | 任意 | 20 個まで、1 個 50 文字 |
| 選択肢 | 四択の誤答。`\|` で区切る。3 個あれば足りる | 任意 | 5 個まで、1 個 500 文字 |

- 先頭行は見出し `表	裏	補足	タグ	選択肢` にする（アプリが読み飛ばす）。
- セルの中にタブを入れない。セルの中の改行は `\n` の 2 文字で書く（バックスラッシュと n）。
- 引用符（`"`）で囲まない。アプリは引用符を解釈せず、そのまま文字として取り込む。
- 表か裏が空の行は取り込まれない。
- 1 回の取り込みは 2000 行まで。
- 文字コードは UTF-8。ファイルにするときは拡張子 `.tsv`。

## 2. 札の 2 つの型

### 用語の札

表に用語、裏にその用語を一意に言い当てられる短い説明を書く。

```
表	裏	補足	タグ	選択肢
TCP	コネクション型で、到達と順序を保証するトランスポート層のプロトコル	TCP: Transmission Control Protocol。第 4 層。UDP との対比で覚える	ネットワーク	
ハイブリッド暗号	データは共通鍵で暗号化し、その共通鍵を公開鍵で暗号化して送る方式	TLS や S/MIME で使う	暗号	
```

アプリには「裏→表」の出題の向きがあり、**裏の説明を見せて表の用語を答えさせる**。
そのため、裏は「読めばその用語に行き着く」説明にする。「重要なプロトコル」のように複数の用語に当てはまる裏は避ける。

### 文章問題の札

表に問題文、裏に正解、選択肢に誤答を書く。アプリが正解と誤答を混ぜて四択にする。

```
表	裏	補足	タグ	選択肢
DNSSEC が提供するものはどれか。	DNS 応答の完全性と出所の真正性	DNSSEC: Domain Name System Security Extensions。署名で改ざんと偽装を検知する。応答の暗号化はしない	文章問題,ネットワーク	DNS 応答の機密性と通信の秘匿性|DNS サーバーの可用性と負荷の分散|ゾーン転送の高速化と応答の圧縮
```

- 問題文は「〜はどれか。」のように、答えが 1 つに決まる形にする。
- **正解（裏）と誤答（選択肢）は、長さと文体と語尾をそろえる。** これが最も重要で、守れていない四択は学習にならない。
  - 正解が 30 文字なら、誤答も 20〜40 文字にする。正解がどの誤答よりも長い札を作らない（アプリは取り込みの前にその数を警告する）。
  - 問題文が「〜するプロトコルはどれか」なら、誤答もすべてプロトコルの名前にする。正解が「P」で終わる略語なら、誤答も「P」で終わる略語から選ぶ。
  - 正解が「〜を防ぐ」で終わるなら、誤答も「〜を防ぐ」で終える。正解が句点や括弧の補足を含むなら、誤答にも同じ形を付ける。
  - 書き終えたら、選択肢を正解と並べて見比べ、正解だけが浮いていないかを確かめる。
- 誤答は「同じ分野で、よく混同されるもの」から選ぶ。無関係な語は学習にならない。
- 誤答に正解と同じ文字列を入れない（アプリが除く）。
- 選択肢の列が空のときは、アプリが同じ単語帳の他の札の裏（裏→表の出題では表）から、正解と語尾が同じで長さの近いものを誤答にする。用語の札は空でよい。

### 略語の札

表や裏が略語（TCP、OCSP、DKIM など）のときは、**補足の先頭に正式名称（英語の綴り）を書く。** 略の意味まで覚えるため。

```
表	裏	補足	タグ	選択肢
OCSP	証明書の失効状態をオンラインで 1 件ずつ問い合わせるプロトコル	OCSP: Online Certificate Status Protocol。CRL は一覧を定期的に取得する	暗号	
```

- 書式は「略語: 正式名称。」で、続けて元の補足を書く。複数あれば「、」で並べる。
- 裏（説明）には正式名称を書かない。裏を見て表を答える出題で、答えがそのまま見えてしまう。

## 3. 出力の仕方

- 全体を 1 つのコードブロック、または `.tsv` のファイルとして出す。説明文を行の間に挟まない。
- 見出し行を 1 行目に付ける。
- 用語の札と文章問題の札を混ぜてよいが、タグで分野が分かるようにする。
- 同じ表の札を重複して作らない。
- 出典や根拠が怪しい内容は、補足に「要確認」と書く。

## 4. 取り込み方（利用者への案内）

1. 単語帳を開き、「TSV から取り込む」を押す。
2. 出力した TSV を貼り付ける。件数が「n 件を取り込む」のボタンに出る。正解がどの誤答よりも長い札があれば、その数が画面に出る。
3. 押すと札が追加される。表か裏が空の行は件数に含まれない。
4. 同じ表の札が既にあれば、その札の裏・補足・タグ・選択肢が書き換わる（学習の進み具合は残る）。誤答や補足を直したときは、同じ TSV を取り込み直せばよい。
